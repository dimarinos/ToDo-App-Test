
# Codex Project Rules

## Project
This is a beginner-friendly web application using
HTML, CSS, and vanilla JavaScript.

## Coding Guardrails
- Keep code simple, readable, and well organized.
- Do not introduce frameworks unless requested.
- Do not install dependencies without approval.
- Do not delete or overwrite unrelated files.
- Never hardcode passwords, API keys, or secrets.
- Do not access files outside this project.
- Ask before making major architectural changes.

## Quality
- Preserve existing working functionality.
- Validate user inputs.
- Avoid unnecessary code duplication.
- Test changes before reporting completion.
- Fix errors introduced by your changes.

## Communication
- Explain major changes in plain English.
- List the files changed.
- Report tests performed and their results.
- State clearly when a test could not be run.
- Ask questions when requirements are unclear.
