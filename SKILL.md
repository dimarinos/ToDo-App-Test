# Beginner Web App Skill

Use this skill when creating a small web application.

## Workflow

1. Understand the requested application.
2. Identify the minimum features needed.
3. Create index.html, style.css, and script.js.
4. Write simple, readable code.
5. Use localStorage when persistent data is needed.
6. Make the design responsive.
7. Test core functionality.
8. Explain how to run the app.

## Restrictions

- No external frameworks by default.
- No unnecessary dependencies.
- No backend unless explicitly requested.
- Follow the project's AGENTS.md instructions.

## Completion

Report:
- Files created or modified
- Features implemented
- Tests performed
- Known limitations
