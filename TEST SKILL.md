# Test Web App Skill

1. Inspect the application's existing files.
2. Check for JavaScript syntax errors.
3. Review event handlers and input validation.
4. Check localStorage read/write behavior.
5. Test available functionality using existing tools.
6. Check mobile responsiveness where possible.
7. Report issues by severity.
8. Fix verified bugs when requested.
9. Never claim a test passed unless it ran.

Do not introduce new features during a bug fix.
Do not delete user data.
